# Templates

Markdown versions of the templates in **Appendix C** of the book. Copy a template into your lab folder before you fill it in.

| File | Use |
|---|---|
| `solution_graph_checklist.md` | Rules W1–W8 — check every solution graph against them |
| `node_card.md` | One card per node in a solution graph |
| `tradeoff_table.md` / `tradeoff.py` | The trade-off table; `tradeoff.py` computes weighted scores and the sensitivity check |
| `failure_walkthrough.md` | Failures of tools, data and people, not only models |
| `decision_record.md` | One per design decision |
| `memo.md` | The one-page memo to the sponsor |
| `go_no_go.md` | Pilot criteria and stop rules |

Draw solution graphs with any tool. The node shapes and edge styles are in Chapter 2, Table 2.1 and Table 2.2.
